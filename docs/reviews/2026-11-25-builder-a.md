## Contrôles

- Les 56 tests Foundry passent. Les deux propriétés de paiement ont également été exécutées avec 1 024 entrées chacune. Les quatre interfaces conservent les 64 signatures gelées.
- Les 20 tests Python passent, dont les reprises après incident, les preuves sans clé de signature et le cycle de vie du processus. La CI découvre désormais tous les fichiers `test_*.py`.
- Les sept contrats de base, leurs arguments de création et les deux apports de liquidité correspondent au journal du déploiement. Sur BSC testnet, la vérification a relu les neuf reçus, la configuration de la factory et les reporters.
- Le [paiement](https://testnet.bscscan.com/tx/0xc358512d795e0ea18e218f5816ecf2f32b386fff1bd5cde742648c15648a079d) et le [swap](https://testnet.bscscan.com/tx/0x3a0dd0b84af9105c542db87e6838dd4b5909c444eaca205d6eda217ac6d4f8c8) ont été revérifiés en lecture seule. Le reçu du swap donne 1 mUSDC pour 1 mUSDT. Une simulation à son bloc a refusé 0,90 mUSDC pour un minimum de 0,978863781006942765.
- Sur le Mac, un second `make start` a conservé le PID. `make stop` a libéré le verrou. Le redémarrage a lancé un nouveau processus et vérifié les deux flux. Le test d’arrêt brutal utilise un processus temporaire isolé.

## Points pour la démo

utilise l’horodatage d’origine et refuse les observations de plus de 25 heures.
L’arrêt de la machine interrompt la surveillance. Après redémarrage, lancer
`make start`. Les composants agent et web sont encore à intégrer sur ces branches.
